## 1. 文档定位

本文针对用户提供的“问界 M6 专属升级方案”海报，规划问界 M6 单车型轻改专题页。

项目中已经存在问界总专题 PRD，原范围主要围绕 M7 / M8 / M9 的车型产品数据，以及问界系列升级方案。本文不覆盖原有问界 PRD，而是补充一个更轻、更具体的 M6 单车型模块：

- 原问界专题解决：问界系列车型和产品款式如何集中展示。
- 问界系列升级 PRD 解决：问界车主如何按热门项目理解轻改方案。
- 本 PRD 解决：问界 M6 车主进入官网后，如何快速理解 17 个 M6 专属升级项目，并展开详情。

一句话定位：

> 问界 M6 专题页是蓝辉面向问界 M6 车主的单车型轻改方案页，用于集中展示车衣、隔热膜、彩绘、电动踏板、360 软包脚垫、铝地板、运动包围、底盘护板、小桌板、抬头显示、钢化膜和门槛条等项目，并引导车主确认适配和施工。

## 2. 页面目标

### 2.1 用户目标

问界 M6 车主进入页面后，需要快速知道：

1. 我的问界 M6 可以做哪些轻改升级项目？
2. 哪些项目适合新车优先做？
3. 哪些项目偏外观运动、座舱舒适或家庭使用？
4. 哪些项目需要到店确认安装位和版本适配？
5. 如何进一步确认方案和施工？

### 2.2 业务目标

蓝辉通过该页面实现：

1. 把“问界 M6 专属升级方案”转成官网可检索、可分享的内容资产。
2. 强化蓝辉对问界新增车型的响应速度和车型方案能力。
3. 给销售提供可直接转发的 M6 专题链接。
4. 通过项目点击和项目兴趣行为判断 M6 车主更关注新车保护、外观升级、电动便利还是座舱舒适。

## 13. 施工服务流程

页面应展示统一服务流程：

```text
车型确认 → 项目选择 → 到店评估 → 方案确认 → 施工安装 → 验收交付 → 售后支持
```

| 步骤 | 说明 |
|---|---|
| 车型确认 | 确认问界 M6 的年份、批次、版本和配置 |
| 项目选择 | 根据保护、外观、电动便利、家庭座舱等分类选择项目 |
| 到店评估 | 确认安装位、接口、材料、工期和风险提示 |
| 方案确认 | 确认项目组合、施工时间和注意事项 |
| 施工安装 | 按项目标准施工，并做好车身和内饰保护 |
| 验收交付 | 检查外观、功能和安装细节 |
| 售后支持 | 提供使用注意事项和后续维护建议 |

## 20. 三棱镜验收标准

### 20.1 实现什么

- 新增问界 M6 单车型升级方案页面或问界专题内 M6 分区。
- 页面完整展示海报中的 17 个项目。
- 页面按场景分类展示项目，而不是只贴海报。
- 页面提供新车保护、家庭座舱、外观运动三类推荐组合。

### 20.2 怎么实现

- 使用静态数据维护 17 个项目，不在组件里散落硬编码。
- 项目卡片支持分类标签、展开说明和项目兴趣行为。
- 海报作为素材模块展示，正文必须有 HTML 文本。
- 图片允许 `pending-review` 状态，后续再逐步匹配真实素材。

### 20.3 怎么验收

| 验收项 | 标准 |
|---|---|
| 项目完整性 | 17 个项目名称与海报一致，无遗漏、无错字 |
| 分类清晰 | 至少覆盖新车保护、外观个性、电动便利、底盘防护、家庭座舱、屏幕维护 |
| 合规表达 | 无官方授权、原厂、不影响质保、100% 无损、性能提升等承诺 |
| 移动端可读 | 17 个项目在手机端可顺畅浏览，不横向溢出 |
| 埋点可测 | 项目点击和项目兴趣点击能带上项目名称与分类 |
| SEO 可读 | 主要项目以 HTML 文本存在，不只存在于图片中 |
