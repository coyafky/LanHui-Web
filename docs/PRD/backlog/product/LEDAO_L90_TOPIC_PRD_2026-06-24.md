## 1. 文档定位

本文只针对用户提供的这张“乐道 L90 专属升级方案”海报，规划一个新的乐道 L90 单车型专题页。

这份 PRD 不讨论整个 Product 系统升级，也不重写其他车型页面。目标是把海报里的内容转成官网页面可执行的产品需求：

- 海报表达的是：乐道 L90 车主可以做哪些热门轻改产品。
- 官网页面要表达的是：蓝辉能为乐道 L90 车主提供哪些结构化轻改方案，以及如何确认。
- 页面不能只是把海报原图贴上去，而要把海报中的项目拆成模块、分类、内容、交互和验收标准。

一句话定位：

> 乐道 L90 专题页是蓝辉面向乐道 L90 车主的单车型轻改项目展示页，用于集中展示车衣、隔热膜、彩绘/改色、铝地板、底盘护板、电动踏板、座舱便利、智能影音和更多可选轻改项目，并说明后续确认方式。

## 2. 页面目标

### 2.1 用户目标

乐道 L90 车主进入页面后，需要快速知道：

1. 我的 L90 可以做哪些热门轻改项目？
2. 哪些是新车最常做的基础保护项目？
3. 哪些是外观个性、座舱舒适和家庭出行升级？
4. 这些项目大概解决什么问题？
5. 我怎么进一步确认适配和施工？

### 2.2 业务目标

蓝辉通过该页面实现：

1. 把“乐道 L90 专属升级方案”做成可传播、可检索、可埋点的官网内容。
2. 强化蓝辉对新上市/热门新能源车型的响应速度和车型方案能力。
3. 给销售和运营一个统一页面，减少反复发送长图海报。
4. 通过项目点击和项目兴趣点击判断乐道 L90 车主最关注的升级方向。

## 3. 用户与车型范围

### 3.1 目标用户

| 用户 | 需求 |
|---|---|
| 乐道 L90 新车车主 | 关注车衣、隔热膜、底盘护板、360脚垫、门槛条等基础保护 |
| 家庭用户 | 关注铝地板、小桌板、腿托、尾箱垫、后排娱乐电视等空间与舒适项目 |

| 门店销售 | 需要把页面发给客户，作为沟通清单 |

### 3.2 车型范围

一期页面明确面向“乐道 L90”单车型，不泛化到乐道全系。

页面需明确说明：

> 不同批次、配置和版本的乐道 L90 在安装结构、接口、尺寸和空间上可能存在差异。页面项目作为轻改方向参考，最终以到店确认和施工评估为准。

### 3.3 不做承诺

页面不得出现以下未经证明的表达：

- 乐道官方授权。
- 蔚来官方合作。
- 原厂配件。
- 不影响原厂质保。
- 100% 无损安装。
- 永久质保。
- 全网最低。

## 11. 施工服务流程

页面应展示蓝辉的服务流程：

```text
车型确认 → 项目选择 → 到店评估 → 施工安装 → 验收交付 → 售后支持
```

每一步建议文案：

| 步骤 | 说明 |
|---|---|
| 车型确认 | 确认乐道 L90 的批次、版本和配置差异 |
| 项目选择 | 根据新车保护、外观个性、家庭后排或行车防护选择项目 |
| 到店评估 | 现场确认安装位置、接口、材料和工期 |
| 施工安装 | 按项目标准施工，过程保护车辆 |
| 验收交付 | 检查外观、功能和安装效果 |
| 售后支持 | 提供使用注意事项和后续维护建议 |
