## 1. 文档定位

本文只针对用户提供的这张“问界系列 项目升级方案”海报，规划问界车型专题页的内容升级方式。

项目中已经存在 2026-06-20 的问界车型专题 PRD，原文重点是按 M7 / M8 / M9 拆分 44 个产品款式，并处理图片规格、三态图片状态和产品表格。

本文不覆盖原 PRD，而是补充一个更适合官网表达的“项目升级方案”层：

- 原 PRD 解决：问界有哪些车型和产品款式。
- 本 PRD 解决：问界车主进入官网后，如何按热门升级项目理解蓝辉的轻改方案。
- 海报表达的是：问界系列有哪些热门升级目录和更多选择。
- 官网页面要表达的是：蓝辉能为问界车主提供哪些结构化轻改方案，以及如何确认。

一句话定位：

> 问界系列项目升级方案页是蓝辉面向问界车主的轻改项目展示层，用于集中展示隐形车衣、隔热膜、二排铝地板、底盘护板、电动踏板、后排便利、智能影音和更多升级项目，并说明后续确认方式。

## 2. 页面目标

### 2.1 用户目标

问界车主进入页面后，需要快速知道：

1. 我的问界车型可以做哪些常见升级项目？
2. 哪些是热门推荐？
3. 哪些项目适合家庭、长途、后排乘坐和日常保护？
4. 这些项目大概解决什么问题？
5. 我怎么进一步确认适配和施工？

### 2.2 业务目标

蓝辉通过该页面实现：

1. 把“问界系列项目升级方案”做成可传播、可检索、可埋点的官网内容。
2. 强化蓝辉在问界车型轻改方案上的专业感。
3. 给销售和运营一个统一页面，减少反复发送长图海报。
4. 通过项目点击和项目兴趣点击判断问界车主最关注的升级方向。

## 3. 用户与车型范围

### 3.1 目标用户

| 用户 | 需求 |
|---|---|
| 问界 M7 / M8 / M9 车主 | 关注隐形车衣、隔热膜、地板、底盘护板、电动踏板等基础升级 |
| 家庭用户 | 关注二排铝地板、小桌板、后排娱乐、旋转座椅、腿托等舒适和便利项目 |
| 长途/露营用户 | 关注车顶平台套件、防虫网、挡泥板、尾箱垫和储物防护 |
| 新车车主 | 想一次性了解新车保护和基础轻改清单 |
| 门店销售 | 需要把页面发给客户，作为沟通清单 |

### 3.2 车型范围

一期页面采用“问界系列”表达，并与原问界 PRD 的 M7 / M8 / M9 车型范围保持兼容。

页面需明确说明：

> 不同年份、版本和配置的问界车型在安装结构、接口、尺寸和空间上可能存在差异。页面项目作为轻改方向参考，最终以到店确认和施工评估为准。

### 3.3 不做承诺

页面不得出现以下未经证明的表达：

- 问界官方授权。
- 华为官方合作。
- 鸿蒙智行官方合作。
- 原厂配件。
- 不影响原厂质保。
- 100% 无损安装。
- 永久质保。
- 全网最低。

| 车型款式层 | 让用户继续按 M7 / M8 / M9 查看具体产品款式 |

## 11. 施工服务流程

页面应展示蓝辉的服务流程：

```text
车型确认 → 项目选择 → 到店评估 → 施工安装 → 验收交付 → 售后支持
```

每一步建议文案：

| 步骤 | 说明 |
|---|---|
| 车型确认 | 确认问界车型、年份、版本和配置差异 |
| 项目选择 | 根据家庭出行、后排舒适、户外场景或新车保护选择项目 |
| 到店评估 | 现场确认安装位置、接口、材料和工期 |
| 施工安装 | 按项目标准施工，过程保护车辆 |
| 验收交付 | 检查外观、功能和安装效果 |
| 售后支持 | 提供使用注意事项和后续维护建议 |

| 工期多久？ | 根据项目组合和施工排期确认 |

  | "exterior_parts"
