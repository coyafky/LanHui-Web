## 1. 文档定位

本文只针对用户提供的这张“极氪 9X 专属升级方案”海报，规划极氪 9X 单车型轻改专题页或极氪总专题中的 9X 升级方案层。

项目中已经存在 2026-06-16 的极氪总专题 PRD，原文重点是按极氪 9X / 8X / 009 拆分产品款式，并处理图片规格、产品数据、三态图片状态和构建期校验。

本文不覆盖原 PRD，而是补充一个更适合官网表达的“9X 专属升级方案”层：

- 原 PRD 解决：极氪系列有哪些车型和产品款式。
- 本 PRD 解决：极氪 9X 车主进入官网后，如何按热门轻改项目理解蓝辉的 9X 专属方案。
- 海报表达的是：极氪 9X 有哪些热门轻改产品目录。
- 官网页面要表达的是：蓝辉能为极氪 9X 车主提供哪些结构化轻改方案，以及如何确认。

一句话定位：

> 极氪 9X 专题页是蓝辉面向极氪 9X 车主的单车型轻改项目展示页，用于集中展示车衣、隔热膜、彩绘/改色、铝地板、底盘护板、360脚垫、门槛条、轮毂、内饰防护和更多可选轻改项目，并说明后续确认方式。

## 2. 页面目标

### 2.1 用户目标

极氪 9X 车主进入页面后，需要快速知道：

1. 我的极氪 9X 可以做哪些热门轻改项目？
2. 哪些是新车最常做的基础保护项目？
3. 哪些是外观个性、座舱保护和底盘防护升级？
4. 这些项目大概解决什么问题？
5. 我怎么进一步确认适配和施工？

### 2.2 业务目标

蓝辉通过该页面实现：

1. 把“极氪 9X 专属升级方案”做成可传播、可检索、可埋点的官网内容。
2. 强化蓝辉在高端新能源 SUV 车型轻改方案上的专业感。
3. 给销售和运营一个统一页面，减少反复发送长图海报。
4. 通过项目点击和项目兴趣点击判断极氪 9X 车主最关注的升级方向。

页面不得出现以下未经证明的表达：

- 极氪官方授权。

- 原厂配件。

## 11. 施工服务流程

页面应展示蓝辉的服务流程：

```text
车型确认 → 项目选择 → 到店评估 → 施工安装 → 验收交付 → 售后支持
```

每一步建议文案：

| 步骤 | 说明 |
|---|---|
| 车型确认 | 确认极氪 9X 的批次、版本和配置差异 |
| 项目选择 | 根据新车保护、外观个性、座舱防护或底盘防护选择项目 |
| 到店评估 | 现场确认安装位置、接口、材料和工期 |
| 施工安装 | 按项目标准施工，过程保护车辆 |
| 验收交付 | 检查外观、功能和安装效果 |
| 售后支持 | 提供使用注意事项和后续维护建议 |
