## 1. 文档定位

本文针对用户提供的“小米系列轻改项目”海报，补充规划小米系列专题页中的轻改升级方案模块。

项目中已经存在小米总专题 PRD，主要解决小米 SU7 / YU7 车型产品展示、图片规格、产品数据结构和专题页实现方式。本文不替代原 PRD，而是把海报中的 21 个轻改项目整理成可落地的官网模块：

- 原小米总专题解决：小米系列产品如何作为车型专题进入官网。
- YU7 PRD 解决：小米 YU7 单车型如何承接 9 个核心轻改项目。
- 本 PRD 解决：小米系列，尤其偏 SU7 / Ultra 风格的轻改项目，如何在官网中按“基础保护、外观性能化、座舱氛围、智能便利”表达。

一句话定位：

> 小米系列轻改项目升级模块，是蓝辉面向小米车主展示“从基础保护到 Ultra 风格升级”的官网方案页，用于承接车衣、隔热膜、改色膜、底盘护板、尾翼、包围、内饰与座舱升级等内容。

## 2. 页面目标

### 2.1 用户目标

小米车主进入页面后，需要快速判断：

1. 我的小米车可以做哪些轻改项目？
2. 哪些项目适合新车先做？
3. 哪些项目偏外观运动化或 Ultra 风格？
4. 哪些项目属于座舱氛围和舒适升级？
5. 如果我只想做一两个项目，是否可以单独了解？

### 2.2 业务目标

蓝辉通过该模块实现：

1. 把“小米系列轻改项目”从一张长图海报，整理为可检索、可点击、可埋点的官网内容。
2. 强化蓝辉对小米热门新能源车型的轻改方案能力。
3. 让销售可以直接发送官网链接，而不是只发送海报长图。
4. 通过项目点击和项目兴趣行为判断小米车主对保护、外观、内饰、灯效、舒适项目的兴趣。

## 12. 施工服务流程

页面应展示统一服务流程：

```text
车型确认 → 项目选择 → 到店评估 → 方案确认 → 施工安装 → 验收交付 → 售后支持
```

| 步骤 | 说明 |
|---|---|
| 车型确认 | 确认小米车型、版本、年份和配置差异 |
| 项目选择 | 根据保护、外观、座舱、Ultra 风格等分类选择项目 |
| 到店评估 | 确认安装位、接口、材料、工期和风险提示 |
| 方案确认 | 对项目组合、价格范围和施工时间进行确认 |
| 施工安装 | 按项目标准施工，并做好车身和内饰保护 |
| 验收交付 | 检查外观效果、功能状态和安装细节 |
| 售后支持 | 提供使用注意事项和后续维护建议 |
