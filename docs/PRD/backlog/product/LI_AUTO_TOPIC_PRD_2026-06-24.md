## 1. 文档定位

本文只针对用户提供的这张“理想系列轻改项目”海报，规划一个新的理想系列车型专题页。

这份 PRD 不讨论整个 Product 系统升级，也不重写其他车型页面。目标是把海报里的内容转成官网页面可执行的产品需求：

- 海报表达的是：理想系列车主可以做哪些轻改项目。
- 官网页面要表达的是：蓝辉能为理想车主提供哪些结构化轻改方案，以及如何确认。
- 页面不能只是把海报原图贴上去，而要把海报中的项目拆成模块、分类、内容、交互和验收标准。

一句话定位：

> 理想系列车型专题页是蓝辉面向 Li Auto / 理想车主的轻改项目展示页，用于集中展示隐形车衣、隔热膜、二排铝地板、底盘护板、电动踏板、后排便利、座舱防护和更多可选升级项目，并说明后续确认方式。

## 2. 页面目标

### 2.1 用户目标

理想车主进入页面后，需要快速知道：

1. 我的理想车型可以做哪些轻改项目？
2. 哪些是新车最常做的保护和基础升级？
3. 哪些是围绕家庭出行、后排舒适和露营场景的进阶项目？
4. 这些项目大概解决什么问题？
5. 我怎么进一步确认适配和施工？

### 2.2 业务目标

蓝辉通过该页面实现：

1. 把“理想系列轻改项目”做成一个可传播、可检索、可埋点的官网页面。
2. 强化蓝辉在家庭型新能源 SUV/MPV 轻改方案上的能力。
3. 给销售和运营一个统一页面，减少反复发送长图海报。
4. 通过项目点击和项目兴趣点击判断理想车主最关注的轻改方向。

## 3. 用户与车型范围

### 3.1 目标用户

| 用户 | 需求 |
|---|---|
| 理想 L 系列车主 | 关注车衣、隔热膜、二排铝地板、底盘护板、电动踏板等基础项目 |
| 家庭用户 | 关注后排娱乐、小桌板、零重力座椅、腿托、香氛等舒适体验 |
| 长途/露营用户 | 关注车顶平台、冰箱、防虫网、底盘护板、储物和防护项目 |
| 新车车主 | 想一次性了解新车保护和基础轻改清单 |
| 门店销售 | 需要把页面发给客户，作为沟通清单 |

### 3.2 车型范围

一期页面采用“理想系列”表达，不做复杂年份/版本适配表。

页面需明确说明：

> 不同年份、版本和配置的理想车型在安装结构、接口、尺寸和空间上可能存在差异。页面项目作为轻改方向参考，最终以到店确认和施工评估为准。

### 3.3 不做承诺

页面不得出现以下未经证明的表达：

- 理想官方授权。
- 原厂配件。
- 不影响原厂质保。
- 100% 无损安装。
- 永久质保。
- 全网最低。

### 7.1 主推项目展示方式

推荐采用“重点卡片 + 分类标签”的方式：

- Desktop：2 行 5 列或 3+3+4 分组。
- Tablet：2 列卡片。
- Mobile：单列卡片。

每张卡片至少包含：

- 项目名称。

## 11. 施工服务流程

页面应展示蓝辉的服务流程：

```text
车型确认 → 项目选择 → 到店评估 → 施工安装 → 验收交付 → 售后支持
```

每一步建议文案：

| 步骤 | 说明 |
|---|---|
| 车型确认 | 确认理想车型、年份、版本和配置差异 |
| 项目选择 | 根据家庭出行、露营、后排舒适或新车保护选择项目 |
| 到店评估 | 现场确认安装位置、接口、材料和工期 |
| 施工安装 | 按项目标准施工，过程保护车辆 |
| 验收交付 | 检查外观、功能和安装效果 |
| 售后支持 | 提供使用注意事项和后续维护建议 |

## 12. 常见问题

建议至少包含：

| 问题 | 回答方向 |
|---|---|
| 是否所有理想车型都能安装？ | 不同年份和配置不同，需到店确认 |
| 新车最推荐先做哪些项目？ | 隐形车衣、隔热膜、底盘护板、门槛条、内饰保护等 |
| 家庭用户最常关注哪些项目？ | 二排铝地板、电动踏板、小桌板、后排娱乐、冰箱和座椅舒适项目 |
| 可以只做单个项目吗？ | 可以，页面只是组合参考 |
| 是否影响原车质保？ | 不做承诺，以车主车辆情况和项目评估为准 |
| 工期多久？ | 根据项目组合和施工排期确认 |

## 15. 数据结构建议

建议新建静态数据文件：

`src/lib/li-auto-products.ts`

核心结构：

```ts
export type LiAutoProjectPriority = "featured" | "optional";
export type LiAutoProjectCategory =
  | "paint_protection"
  | "film_style"
  | "chassis_protection"
  | "rear_cabin"
  | "electric_convenience"
  | "infotainment"
  | "exterior_parts"
  | "outdoor_accessory"
  | "cabin_comfort";

export type LiAutoProject = {
  key: string;
  name: string;
  category: LiAutoProjectCategory;
  priority: LiAutoProjectPriority;
  order: number;
  summary: string;
  applicableModels?: string[];
  imageStatus: "matched" | "pending-review" | "missing";
};
```

一期可以先不为每个项目准备独立图片，允许 `imageStatus = "pending-review"`。
