## 1. 文档定位

本文针对用户提供的“高山8 专属升级方案”海报，规划高山8 单车型轻改专题页。

这张海报项目数量较多，既包含车衣、隔热膜、脚垫、铝地板、底盘护板等新车基础项目，也包含 AMXT 包围、BSKT 运动包围、黑化 81 件套、车标灯、日行灯、电动踏板、中开门、香氛系统等更偏 MPV 商务/外观/舒适体验的升级项目。

官网页面不能只是展示长图，而要把海报中的 23 个项目拆成可阅读、可筛选、可检索、可埋点的网页内容。

一句话定位：

> 高山8 专题页是蓝辉面向高端新能源 MPV 车主的单车型轻改方案页，用于集中展示新车保护、商务外观、灯光氛围、电动便利、后排舒适和内饰防护等升级项目，并说明适配与施工边界。

## 2. 页面目标

### 2.1 用户目标

高山8 车主进入页面后，需要快速知道：

1. 我的高山8 可以做哪些轻改升级项目？

## 12. 施工服务流程

页面应展示统一服务流程：

```text
车型确认 → 项目选择 → 到店评估 → 方案确认 → 施工安装 → 验收交付 → 售后支持
```

| 步骤 | 说明 |
|---|---|
| 车型确认 | 确认高山8 的年份、批次、版本和配置 |
| 项目选择 | 根据保护、商务外观、灯光、电动便利、后排舒适等分类选择项目 |
| 到店评估 | 确认安装位、接口、材料、工期和灯光/电动件注意事项 |
| 方案确认 | 确认项目组合、施工时间和注意事项 |
| 施工安装 | 按项目标准施工，并做好车身和内饰保护 |
| 验收交付 | 检查外观、功能和安装细节 |
| 售后支持 | 提供使用注意事项和后续维护建议 |

## 19. 三棱镜验收标准

### 19.1 实现什么

- 新增高山8 单车型升级方案页面。
- 页面完整展示海报中的 23 个项目。
- 页面明确提示灯光、电动件、黑化套件和刹车卡钳等特殊项目的适配/合规边界。
- 页面按场景分类展示项目，而不是只贴海报。
- 页面提供新车保护、商务外观、MPV 舒适、灯光视觉四类推荐组合。

### 19.2 怎么实现

- 使用静态数据维护 23 个项目，不在组件里散落硬编码。
- 项目卡片支持分类标签、项目类型、展开说明和项目兴趣行为。
- 海报作为素材模块展示，正文必须有 HTML 文本。
- 图片允许 `pending-review` 状态，后续再逐步匹配真实素材。

### 19.3 怎么验收

| 验收项 | 标准 |
|---|---|
| 项目完整性 | 23 个项目名称与海报一致，无遗漏、无错字 |
| 特殊项目提示 | 灯光、电动件、黑化套件、刹车卡钳必须有适配或合规提示 |
| 分类清晰 | 至少覆盖新车保护、商务外观、外观个性、MPV 舒适、底盘防护、屏幕保护 |
| 合规表达 | 无官方授权、原厂、不影响质保、100% 无损、性能提升等承诺 |
| 移动端可读 | 23 个项目在手机端可顺畅浏览，不横向溢出 |
| 埋点可测 | 项目点击和项目兴趣点击能带上项目名称、分类和项目类型 |
| SEO 可读 | 主要项目以 HTML 文本存在，不只存在于图片中 |

## 20. 暂不做范围

一期暂不做：

- 在线报价。
- 项目购物车。
- 用户预约排期系统。
- 支付功能。
- 客户案例详情页。
- 每个项目独立详情页。
- 官方参数对比。
- 灯光/电动件的线上适配自动判断。

这些内容可以在后台 CMS、案例系统和预约系统稳定后再进入下一版。
