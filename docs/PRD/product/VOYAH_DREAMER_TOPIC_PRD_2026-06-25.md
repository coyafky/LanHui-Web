## 1. 文档定位

本文针对用户提供的“岚图梦想家专属升级方案”海报，规划岚图梦想家单车型轻改专题页。

这张海报表达的是：岚图梦想家车主可以围绕新车保护、外观个性、底盘防护、MPV 后排舒适、座舱氛围和智能屏幕保护进行轻改升级。官网页面不能只是展示长图，而要把海报中的项目拆成可阅读、可筛选、可检索、可埋点的网页内容。

一句话定位：

> 岚图梦想家专题页是蓝辉面向高端新能源 MPV 车主的单车型升级方案页，用于集中展示车衣、隔热膜、彩绘、双拼改色、360 软包脚垫、铝地板、包围、底盘护板、门槛条、氛围灯、腿托和内饰防护等项目，并说明适配与施工边界。

## 2. 页面目标

### 2.1 用户目标

岚图梦想家车主进入页面后，需要快速知道：

1. 我的岚图梦想家可以做哪些轻改升级项目？
2. 哪些项目适合新车优先做？
3. 哪些项目适合 MPV 家庭/商务后排场景？
4. 哪些项目偏外观个性、运动包围或视觉升级？
5. 如何确认版本、配置和施工适配？

### 2.2 业务目标

蓝辉通过该页面实现：

1. 把“岚图梦想家专属升级方案”转成官网可检索、可分享的内容资产。
2. 强化蓝辉在新能源 MPV 轻改、后排舒适和高端商务用车升级上的专业表达。
3. 给销售提供可直接转发的车型专题链接，减少只转发海报的沟通成本。
4. 通过项目点击和项目兴趣行为判断梦想家车主更关注保护、外观、后排舒适还是内饰维护。

## 12. 施工服务流程

页面应展示统一服务流程：

```text
车型确认 → 项目选择 → 到店评估 → 方案确认 → 施工安装 → 验收交付 → 售后支持
```

| 步骤 | 说明 |
|---|---|
| 车型确认 | 确认岚图梦想家的年份、批次、版本和配置 |
| 项目选择 | 根据保护、外观、后排舒适、座舱维护等分类选择项目 |
| 到店评估 | 确认安装位、接口、材料、工期和风险提示 |
| 方案确认 | 确认项目组合、施工时间和注意事项 |
| 施工安装 | 按项目标准施工，并做好车身和内饰保护 |
| 验收交付 | 检查外观、功能和安装细节 |
| 售后支持 | 提供使用注意事项和后续维护建议 |

### 19.1 实现什么

- 新增岚图梦想家单车型升级方案页面。
- 页面完整展示海报中的 17 个项目。
- 页面按场景分类展示项目，而不是只贴海报。
- 页面提供新车保护、MPV 后排舒适、外观个性三类推荐组合。

### 19.2 怎么实现

- 使用静态数据维护 17 个项目，不在组件里散落硬编码。
- 项目卡片支持分类标签、展开说明和项目兴趣行为。
- 海报作为素材模块展示，正文必须有 HTML 文本。
- 图片允许 `pending-review` 状态，后续再逐步匹配真实素材。

### 19.3 怎么验收

| 验收项 | 标准 |
|---|---|
| 项目完整性 | 17 个项目名称与海报一致，无遗漏、无错字 |
| 分类清晰 | 至少覆盖新车保护、外观个性、底盘防护、MPV 后排舒适、座舱维护 |
| 合规表达 | 无官方授权、原厂、不影响质保、100% 无损、性能提升等承诺 |
| 移动端可读 | 17 个项目在手机端可顺畅浏览，不横向溢出 |
| 埋点可测 | 项目点击和项目兴趣点击能带上项目名称与分类 |
| SEO 可读 | 主要项目以 HTML 文本存在，不只存在于图片中 |

## 20. 暂不做范围

一期暂不做：

- 在线报价。
- 项目购物车。
- 用户预约排期系统。
- 支付功能。
- 客户案例详情页。
- 每个项目独立详情页。
- 官方参数对比。

这些内容可以在后台 CMS、案例系统和预约系统稳定后再进入下一版。
