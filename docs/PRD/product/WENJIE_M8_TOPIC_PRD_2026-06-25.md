## 1. 文档定位

本文针对用户提供的“问界 M8 专属升级方案”海报，规划问界 M8 单车型轻改专题页。

项目中已有问界总专题 PRD，M8 在旧文档中主要作为 22 条产品款式数据存在。本文不覆盖旧的问界专题数据，而是新增一个面向销售转发和官网内容的 M8 专属升级方案页。

这张海报同样采用三层结构：

1. **必改产品**：隔热膜、车衣、三防软包脚垫、底盘护板、电动踏板。
2. **高级商务升级**：后排娱乐、氛围灯、小桌板、铝地板、电动门、轮毂、平衡杆、流媒体后视镜、星空顶、星空膜、运动包围、车顶平台套件、改色、腿托、刹车卡钳。
3. **实用小配件**：门槛条、牌照框、钢化膜、防虫网、四门密封条、尾箱垫、内饰硅胶件、挡泥板、内衬、四门隔音。

一句话定位：

> 问界 M8 专题页是蓝辉面向问界 M8 车主的单车型轻改方案页，用于将必改产品、高级商务升级和实用小配件三层项目结构化展示，并重点展示电动门、后排娱乐、铝地板、星空顶/膜等商务舒适升级内容。

## 2. 页面目标

### 2.1 用户目标

问界 M8 车主进入页面后，需要快速知道：

1. 我的问界 M8 必做哪些基础保护？
2. 高级商务升级里哪些项目最适合后排和家庭场景？
3. 电动门、车顶平台、四门隔音等项目是否需要单独确认适配？
4. 哪些实用小配件可以单项做，哪些适合打包做？
5. 如何确认版本、结构、工期和施工注意事项？

### 2.2 业务目标

蓝辉通过该页面实现：

1. 把“问界 M8 专属升级方案”转成官网可检索、可分享的内容资产。
2. 让问界 M8 的销售表达从“项目列表”升级为“必改 / 商务 / 小配件”三层结构。
3. 给销售提供可直接转发的 M8 专题链接。
4. 通过项目点击和项目兴趣行为判断 M8 用户更关注基础保护、电动便利、商务座舱、外观运动还是实用配件。

## 12. 施工服务流程

```text
车型确认 → 项目选择 → 到店评估 → 方案确认 → 施工安装 → 验收交付 → 售后支持
```

| 步骤 | 说明 |
|---|---|
| 车型确认 | 确认问界 M8 的年份、批次、版本和配置 |
| 项目选择 | 根据必改、商务、小配件或使用场景选择项目 |
| 到店评估 | 确认安装位、接口、材料、工期和风险提示，尤其是电动门等结构件 |
| 方案确认 | 确认项目组合、施工时间和注意事项 |
| 施工安装 | 按项目标准施工，并做好车身和内饰保护 |
| 验收交付 | 检查外观、功能和安装细节 |
| 售后支持 | 提供使用注意事项和后续维护建议 |

## 19. 三棱镜验收标准

### 19.1 实现什么

- 新增问界 M8 单车型升级方案页面或问界专题内 M8 升级分区。
- 页面完整展示海报中的 30 个项目。
- 页面保留“必改产品 / 高级商务升级 / 实用小配件”三层结构。
- 页面明确标注电动门属于高级商务升级，并提示适配确认。

### 19.2 怎么实现

- 使用静态数据维护 30 个项目，不在组件里散落硬编码。
- 项目卡片支持层级标签、分类标签、展开说明和项目兴趣行为。
- 海报作为素材模块展示，正文必须有 HTML 文本。
- 图片允许 `pending-review` 状态，后续再逐步匹配真实素材。

### 19.3 怎么验收

| 验收项 | 标准 |
|---|---|
| 项目完整性 | 30 个项目名称与海报一致，无遗漏、无错字 |
| 层级完整 | 必改产品 5 项、高级商务升级 15 项、实用小配件 10 项 |
| 电动门提示 | 电动门必须有车型版本、门体结构和到店评估提示 |
| 合规表达 | 无官方授权、原厂、不影响质保、100% 无损、性能提升等承诺 |
| 移动端可读 | 30 个项目在手机端分区清晰，不横向溢出 |
| 埋点可测 | 项目点击和项目兴趣点击能带上项目名称、分类和层级 |
| SEO 可读 | 主要项目以 HTML 文本存在，不只存在于图片中 |
