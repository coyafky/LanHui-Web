## 1. 文档定位

本文只针对用户提供的这张“腾势 D9 专属升级方案”海报，规划一个新的腾势 D9 单车型专题页。

这份 PRD 不讨论整个 Product 系统升级，也不重写其他车型页面。目标是把海报里的内容转成官网页面可执行的产品需求：

- 海报表达的是：腾势 D9 车主可以做哪些热门轻改产品。
- 官网页面要表达的是：蓝辉能为腾势 D9 车主提供哪些结构化轻改方案，以及如何确认。
- 页面不能只是把海报原图贴上去，而要把海报中的项目拆成模块、分类、内容、交互和验收标准。

一句话定位：

> 腾势 D9 专题页是蓝辉面向腾势 D9 车主的单车型轻改项目展示页，用于集中展示车衣、隔热膜、彩绘/改色、360软包脚垫、铝地板、底盘护板、小桌板、智能影音、灯光外观和更多可选轻改项目，并说明后续确认方式。

## 2. 页面目标

### 2.1 用户目标

腾势 D9 车主进入页面后，需要快速知道：

1. 我的 D9 可以做哪些热门轻改项目？
2. 哪些是新车最常做的基础保护项目？
3. 哪些适合商务接待、家庭出行和后排舒适升级？
4. 这些项目大概解决什么问题？
5. 我怎么进一步确认适配和施工？

### 2.2 业务目标

蓝辉通过该页面实现：

1. 把“腾势 D9 专属升级方案”做成可传播、可检索、可埋点的官网内容。
2. 强化蓝辉在新能源 MPV 轻改方案上的专业感。
3. 给销售和运营一个统一页面，减少反复发送长图海报。
4. 通过项目点击和项目兴趣点击判断腾势 D9 车主最关注的升级方向。

### 3.3 不做承诺

页面不得出现以下未经证明的表达：

- 腾势官方授权。
- 比亚迪官方合作。
- 原厂配件。
- 不影响原厂质保。
- 100% 无损安装。

## 10. 施工服务流程

页面应展示蓝辉的服务流程：

```text
车型确认 → 项目选择 → 到店评估 → 施工安装 → 验收交付 → 售后支持
```

每一步建议文案：

| 步骤 | 说明 |
|---|---|
| 车型确认 | 确认腾势 D9 的年份、版本和配置差异 |
| 项目选择 | 根据新车保护、后排体验、商务接待或外观升级选择项目 |
| 到店评估 | 现场确认安装位置、接口、材料和工期 |
| 施工安装 | 按项目标准施工，过程保护车辆 |
| 验收交付 | 检查外观、功能和安装效果 |
| 售后支持 | 提供使用注意事项和后续维护建议 |
