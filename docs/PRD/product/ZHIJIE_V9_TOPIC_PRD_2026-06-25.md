## 1. 文档定位

本文针对用户提供的“智界 V9 专属升级方案”海报，规划智界 V9 单车型轻改专题页。

这张海报项目数量不算多，但结构很清晰：以车衣、隔热膜、彩绘、改色膜作为外观与新车保护入口，以 360 脚垫、铝地板、门槛条、内饰/座舱保护承接 MPV/商务座舱场景，再以钢化膜、抬头显示罩补足屏幕和显示区域保护。

一句话定位：

> 智界 V9 专题页是蓝辉面向智界 V9 车主的单车型轻改方案页，用于集中展示新车保护、外观个性、座舱地板与门槛保护、行车防护和屏幕显示保护等项目，并说明适配与施工边界。

## 2. 页面目标

### 2.1 用户目标

智界 V9 车主进入页面后，需要快速知道：

1. 我的智界 V9 可以做哪些轻改升级项目？
2. 哪些项目适合新车优先做？
3. 哪些项目适合家庭/商务 MPV 的座舱保护和后排易清洁？
4. 哪些项目属于屏幕、显示区域和门槛高频使用保护？
5. 如何确认版本适配、施工方式和工期？

### 2.2 业务目标

蓝辉通过该页面实现：

1. 把“智界 V9 专属升级方案”转成官网可检索、可分享的内容资产。
2. 强化蓝辉在新能源 MPV / 商务车型轻改方案上的专业表达。
3. 给销售提供可直接转发的车型专题链接。
4. 通过项目点击和项目兴趣行为判断智界 V9 用户更关注新车保护、外观个性、座舱保护还是屏幕显示保护。

## 12. 施工服务流程

页面应展示统一服务流程：

```text
车型确认 → 项目选择 → 到店评估 → 方案确认 → 施工安装 → 验收交付 → 售后支持
```

| 步骤 | 说明 |
|---|---|
| 车型确认 | 确认智界 V9 的年份、批次、版本和配置 |
| 项目选择 | 根据保护、外观、座舱、底盘、屏幕显示等分类选择项目 |
| 到店评估 | 确认安装位、接口、材料、工期和风险提示 |
| 方案确认 | 确认项目组合、施工时间和注意事项 |
| 施工安装 | 按项目标准施工，并做好车身和内饰保护 |
| 验收交付 | 检查外观、功能和安装细节 |
| 售后支持 | 提供使用注意事项和后续维护建议 |

## 19. 三棱镜验收标准

### 19.1 实现什么

- 新增智界 V9 单车型升级方案页面。
- 页面完整展示海报中的 14 个项目。
- 页面按场景分类展示项目，而不是只贴海报。

### 19.2 怎么实现

- 使用静态数据维护 14 个项目，不在组件里散落硬编码。
- 项目卡片支持分类标签、展开说明和项目兴趣行为。
- 海报作为素材模块展示，正文必须有 HTML 文本。
- 图片允许 `pending-review` 状态，后续再逐步匹配真实素材。

### 19.3 怎么验收

| 验收项 | 标准 |
|---|---|
| 项目完整性 | 14 个项目名称与海报一致，无遗漏、无错字 |
| 分类清晰 | 至少覆盖新车保护、外观个性、座舱保护、底盘防护、屏幕保护 |
| 合规表达 | 无官方授权、原厂、不影响质保、100% 无损、性能提升等承诺 |
| 移动端可读 | 14 个项目在手机端可顺畅浏览，不横向溢出 |
| 埋点可测 | 项目点击和项目兴趣点击能带上项目名称与分类 |
| SEO 可读 | 主要项目以 HTML 文本存在，不只存在于图片中 |

## 20. 暂不做范围

一期暂不做：

- 在线报价。
- 项目购物车。
- 用户预约排期系统。
- 支付功能。
- 客户案例详情页。
- 每个项目独立详情页。
- 官方参数对比。

这些内容可以在后台 CMS、案例系统和预约系统稳定后再进入下一版。
