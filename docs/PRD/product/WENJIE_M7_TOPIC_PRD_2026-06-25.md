## 1. 文档定位

本文针对用户提供的“问界 M7 专属升级方案”海报，规划问界 M7 单车型轻改专题页。

项目中已经存在问界总专题 PRD，其中 M7 只作为车型产品数据的一部分，原有范围更偏产品款式和图片规格。本文不覆盖原有问界专题，而是新增一个更适合官网内容的 M7 单车型升级方案。

这张海报已经天然分成三层：

1. **必改产品**：新车保护和基础防护。
2. **高级商务升级**：后排娱乐、座舱舒适、外观运动和户外拓展。
3. **实用小配件**：门槛、牌照框、屏幕、密封、隔音、内饰小件等高频细节。

一句话定位：

> 问界 M7 专题页是蓝辉面向问界 M7 车主的单车型轻改方案页，用于将必改产品、高级商务升级和实用小配件三层项目结构化展示，并说明后续确认方式适配、组合方案和施工。

## 2. 页面目标

### 2.1 用户目标

问界 M7 车主进入页面后，需要快速知道：

1. 我的问界 M7 必做哪些基础轻改？
2. 如果想提升商务感和后排体验，有哪些升级项目？
3. 哪些小配件适合日常防护和细节补强？
4. 哪些项目适合组合做，哪些可以单独做？
5. 如何确认版本适配、施工工期和注意事项？

### 2.2 业务目标

蓝辉通过该页面实现：

1. 把“问界 M7 专属升级方案”转成官网可检索、可分享的内容资产。
2. 将 M7 项目从简单列表升级为“必改 / 商务 / 小配件”三层销售表达。
3. 给销售提供可直接转发的 M7 专题链接。
4. 通过项目点击和项目兴趣行为判断 M7 用户更关注基础保护、商务升级、外观运动、座舱舒适还是实用配件。

## 12. 施工服务流程

页面应展示统一服务流程：

```text
车型确认 → 项目选择 → 到店评估 → 方案确认 → 施工安装 → 验收交付 → 售后支持
```

| 步骤 | 说明 |
|---|---|
| 车型确认 | 确认问界 M7 的年份、批次、版本和配置 |
| 项目选择 | 根据必改、商务、小配件或使用场景选择项目 |
| 到店评估 | 确认安装位、接口、材料、工期和风险提示 |
| 方案确认 | 确认项目组合、施工时间和注意事项 |
| 施工安装 | 按项目标准施工，并做好车身和内饰保护 |
| 验收交付 | 检查外观、功能和安装细节 |
| 售后支持 | 提供使用注意事项和后续维护建议 |

## 19. 三棱镜验收标准

### 19.1 实现什么

- 新增问界 M7 单车型升级方案页面或问界专题内 M7 升级分区。
- 页面完整展示海报中的 30 个项目。
- 页面保留“必改产品 / 高级商务升级 / 实用小配件”三层结构。
- 页面按场景分类展示项目，而不是只贴海报。
- 页面提供必改、商务座舱、外观运动、实用小配件四类推荐组合。

### 19.2 怎么实现

- 使用静态数据维护 30 个项目，不在组件里散落硬编码。
- 项目卡片支持层级标签、分类标签、展开说明和项目兴趣行为。
- 海报作为素材模块展示，正文必须有 HTML 文本。
- 图片允许 `pending-review` 状态，后续再逐步匹配真实素材。

### 19.3 怎么验收

| 验收项 | 标准 |
|---|---|
| 项目完整性 | 30 个项目名称与海报一致，无遗漏、无错字 |
| 层级完整 | 必改产品 5 项、高级商务升级 15 项、实用小配件 10 项 |
| 分类清晰 | 至少覆盖新车保护、商务座舱、外观运动、户外拓展、实用细节 |
| 合规表达 | 无官方授权、原厂、不影响质保、100% 无损、性能提升等承诺 |
| 移动端可读 | 30 个项目在手机端分区清晰，不横向溢出 |
| 埋点可测 | 项目点击和项目兴趣点击能带上项目名称、分类和层级 |
| SEO 可读 | 主要项目以 HTML 文本存在，不只存在于图片中 |
