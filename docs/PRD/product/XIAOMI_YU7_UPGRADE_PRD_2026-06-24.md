## 1. 文档定位

本文只针对用户提供的这张“小米 YU7 专属轻改方案”海报，规划小米 YU7 单车型轻改专题页或小米总专题中的 YU7 升级方案层。

项目中已经存在 2026-06-20 的小米总专题 PRD，原文重点是按 SU7 / YU7 拆分 18 个产品款式，并处理图片规格、产品数据和三态图片状态。

本文不覆盖原 PRD，而是补充一个更适合官网表达的“YU7 专属轻改方案”层：

- 原 PRD 解决：小米 SU7 / YU7 有哪些车型款式。
- 本 PRD 解决：小米 YU7 车主进入官网后，如何按热门轻改项目理解蓝辉的 YU7 专属方案。
- 海报表达的是：小米 YU7 有 9 个核心轻改项目。
- 官网页面要表达的是：蓝辉能为小米 YU7 车主提供哪些结构化轻改方案，以及如何确认。

一句话定位：

> 小米 YU7 专题页是蓝辉面向小米 YU7 车主的单车型轻改项目展示页，用于集中展示软包脚垫、碳纤维护板、平衡杆、运动包围、星空膜/卷帘、香氛系统、电吸门和挡泥板等轻改项目，并说明后续确认方式。

## 2. 页面目标

### 2.1 用户目标

小米 YU7 车主进入页面后，需要快速知道：

1. 我的 YU7 可以做哪些轻改项目？
2. 哪些是新车最常做的基础保护项目？
3. 哪些是外观运动、座舱氛围和电动便利升级？
4. 这些项目大概解决什么问题？
5. 我怎么进一步确认适配和施工？

### 2.2 业务目标

蓝辉通过该页面实现：

1. 把“小米 YU7 专属轻改方案”做成可传播、可检索、可埋点的官网内容。
2. 强化蓝辉对热门新能源新车型的响应速度和车型方案能力。
3. 给销售和运营一个统一页面，减少反复发送长图海报。
4. 通过项目点击和项目兴趣点击判断小米 YU7 车主最关注的升级方向。

## 3. 用户与车型范围

### 3.1 目标用户

| 用户 | 需求 |
|---|---|
| 小米 YU7 新车车主 | 关注软包脚垫、护板、挡泥板等基础保护 |
| 外观运动用户 | 关注运动包围、平衡杆、碳纤维护板等运动/质感升级 |
| 座舱氛围用户 | 关注星空膜、星空卷帘、香氛系统 |
| 电动便利用户 | 关注电吸门等便利项目 |
| 门店销售 | 需要把页面发给客户，作为沟通清单 |

### 3.2 车型范围

一期页面明确面向“小米 YU7”单车型，不泛化到小米全系。

页面需明确说明：

> 不同批次、版本和配置的小米 YU7 在安装结构、接口、尺寸和空间上可能存在差异。页面项目作为轻改方向参考，最终以到店确认和施工评估为准。

### 3.3 不做承诺

页面不得出现以下未经证明的表达：

- 小米官方授权。
- 雷军官方背书。
- 原厂配件。
- 不影响原厂质保。
- 100% 无损安装。
- 永久质保。
- 全网最低。

## 7. 9 个核心轻改项目

海报中的核心内容是 9 个轻改项目。官网页面必须优先结构化展示这些项目。

| 序号 | 项目 | 分类 | 页面表达重点 |
|---:|---|---|---|
| 01 | 软包脚垫 | 座舱保护 | 地毯保护、易清洁、座舱完整感 |
| 02 | 碳纤维护板 | 底盘/防护 | 底部或关键区域保护，强调轻量质感和防护感 |
| 03 | 平衡杆 | 底盘/操控 | 提升车身支撑和驾驶稳定感，需到店评估 |
| 04 | 运动包围 | 外观套件 | 强化外观运动感和整车辨识度 |
| 05 | 星空膜 | 玻璃膜/座舱氛围 | 天幕/玻璃视觉氛围，提升座舱个性 |
| 06 | 星空卷帘 | 遮阳/座舱氛围 | 天幕遮阳和氛围装饰，提升乘坐舒适 |
| 07 | 香氛系统 | 座舱舒适 | 提升座舱气味体验和精致感 |
| 08 | 电吸门 | 电动便利 | 关门便利、科技感和豪华感升级 |
| 09 | 挡泥板 | 防护配件 | 减少泥水飞溅和车身侧面污染 |

### 7.1 项目展示方式

| 层级 | 作用 |

## 11. 施工服务流程

页面应展示蓝辉的服务流程：

```text
车型确认 → 项目选择 → 到店评估 → 施工安装 → 验收交付 → 售后支持
```

每一步建议文案：

| 步骤 | 说明 |
|---|---|
| 车型确认 | 确认小米 YU7 的批次、版本和配置差异 |
| 项目选择 | 根据新车保护、外观运动、座舱氛围或电动便利选择项目 |
| 到店评估 | 现场确认安装位置、接口、材料和工期 |
| 施工安装 | 按项目标准施工，过程保护车辆 |
| 验收交付 | 检查外观、功能和安装效果 |
| 售后支持 | 提供使用注意事项和后续维护建议 |
