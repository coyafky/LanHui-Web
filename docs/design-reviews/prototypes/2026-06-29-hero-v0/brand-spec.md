# LANHUI Hero v0 Brand Spec

This prototype uses local project assets only. It is a product-display hero exploration, not a high-pressure conversion landing page.

## Positioning

- Brand: 蓝辉轻改 LANHUI
- Page role: product-display brand homepage hero
- Primary audience:新能源车主
- Secondary audience: product/channel/cooperation viewers
- Main user job: understand product modules, vehicle-fit direction, and where to browse next

## Visual System

- Background: graphite black / zinc black
- Primary accent: LANHUI orange / amber
- Secondary accent: electric blue
- Material neutrals: silver, smoke, charcoal
- Radius: 8-12px for product surfaces
- Motion: quiet hover/selection feedback only

## Content Assumptions

- CTA should be low-pressure: "查看产品中心", "按车型查看", "获取产品资料".
- Hero should not lead with "预约", "报价", or "加盟".
- Missing real product imagery should be represented as explicit asset needs, not fabricated visuals.
