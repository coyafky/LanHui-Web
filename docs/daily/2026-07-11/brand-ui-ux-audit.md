# `/brand` 品牌页 UI / UX 审计与可部署改进方案

审计日期：2026-07-11  
视口：390×844、768×1024、1440×1000  
方法：Playwright Chromium 生产模式、axe WCAG 2 A/AA/2.1 AA、品牌内容与关联页面核对

## 结论

品牌页当前布局稳定、信息简洁，但更像一份“品牌简介草稿”，还不是能够建立信任、解释差异并推动到店的品牌证明页。

页面主要依赖自述：2026 年成立、从顺德大良出发、轻量/实用/审美、规范施工。没有真实门店、团队、施工、材料、案例或资质证据承接这些表达；主内容区没有任何链接或按钮，用户看完后只能进入 Footer。

建议不要优先做更多渐变和图标卡，而是重构“品牌主张 → 真实证据 → 服务标准 → 门店与行动”的叙事链路。

## 实测摘要

- 390px 页面总高 3916px，其中主内容约 2747px，Footer 约占 1169px。
- 768px 页面总高 2869px。
- 1440px 页面总高 2275px。
- 三个视口均无横向溢出，页面返回 200，无运行时异常。
- 主内容区链接数：0。
- 主内容区按钮数：0。
- 页面只有 2 张位图，均为 Header / Footer 的同一 Logo；品牌主体没有任何图片。
- 主内容只有 5 个 SVG 图标。
- axe 检出 19 个严重级 `color-contrast` 节点，主要集中在 Footer 低对比度文本和链接。
- 标题语义中 `ABOUT LANHUI` 使用 H2，真正的“关于蓝辉轻改”使用 H3，视觉眉题占用了内容标题层级。
- “2026 年成立”在 Hero、关于段落、发展起点中重复出现三次，但没有更多实质品牌历程或证据。

## P0：品牌可信度与内容边界

### 1. 先处理资质页面的占位内容

虽然 `/brand` 主内容没有链接到资质页，但 Header 已提供“资质证书”入口。该页面目前展示 6 类占位证书，包括“汽车后市场服务备案”“贴膜技师认证”“消费者权益保护承诺”等，颁发方、日期、有效期均写“待补充”，证书视觉也是 Emoji 和占位图。

这会给用户造成“品牌已有这些资质，只是编号未展示”的印象。对品牌信任页来说，占位证书比不展示更危险。

立即可部署方案：

- 真实证书未准备好前，将资质页设为不公开或明确改成“资质信息整理中”，不要列出未经确认的证书名称。
- 从 Header、sitemap、SEO metadata 中暂时移除占位证书入口。
- 真实证书上线时展示脱敏扫描件、证书名称、主体、颁发方、编号后四位、签发时间、有效期和核验方式。
- 每份证书增加 `verified` 状态；只有审核通过的记录才能公开。
- 禁止使用 Emoji 作为证书徽章或权威符号。

涉及文件：`src/app/brand/certifications/page.tsx`、`src/lib/certifications.ts`、`src/components/CertCard.tsx`、`src/components/Header.tsx`、`src/app/sitemap.ts`。

### 2. 所有品牌事实必须可验证

品牌页和关联历程页包含以下事实性声明：

- 2026 年成立 / Q1 成立。
- 顺德大良店筹建、正式开放。
- 规范施工、售后跟进。
- 更多城市门店正在筹备。
- 官网与产品矩阵在 Q2 发布。

这些内容应由业务方确认具体适用范围。不要用时间线的视觉形式放大尚未完成或尚未发生的里程碑。

可部署方案：

- 历程数据增加 `status: completed | in_progress | planned`。
- 只有 `completed` 才使用确定语气和具体日期。
- `planned` 明确标记“计划”，不能写成已经发生。
- “规范施工”“不动原车结构”等承诺增加项目/车型适用条件。
- 品牌事实建立单一数据源，避免首页、品牌页、历史页和 Metadata 相互矛盾。

涉及文件：`src/lib/brand.ts`、`src/lib/history.ts`、`src/app/brand/page.tsx`、`src/app/brand/history/page.tsx`。

### 3. Footer 占位联系方式继续削弱品牌页可信度

品牌页底部仍展示“详细地址待补充”“联系方式待补充”“营业时间待确认”、示例邮箱和待备案信息。用户刚看完品牌理念和规范施工，就遇到未完成联系方式，信任会明显下降。

建议沿用首页审计结论：真实数据未确认前隐藏对应字段，不在生产页面展示“待补充”或示例值。

## P1：重构品牌叙事

### 1. Hero 不应只写“品牌介绍”

“品牌介绍”描述的是页面类型，不是品牌价值。Hero 应在 5 秒内回答：

- 蓝辉是谁？
- 为哪类车主服务？
- 与普通改装店有什么不同？
- 用户下一步可以做什么？

推荐结构：

- Eyebrow：`LANHUI 蓝辉轻改`
- H1：`让新能源车型升级，更有型，也更好用`
- 支撑句：`从车型适配、产品选择到顺德大良到店施工的一站式轻改服务。`
- 主 CTA：`获取车型方案`
- 次 CTA：`查看顺德大良店`
- 右侧/背景：真实完成车辆或施工工位图片。

页面标题和 SEO 仍可保留“品牌介绍”，但不需要占据视觉主标题。

### 2. 用“为什么存在”替代产品清单复述

当前“关于蓝辉轻改”主要再次列举电动踏板、轮毂、底盘、窗膜、改色膜和车衣，与首页和产品中心重复。

品牌页更应该解释：

- 为什么创立蓝辉。
- 车主在传统改装/贴膜服务中遇到什么问题。
- 蓝辉如何通过车型适配、透明沟通、标准施工和售后记录解决问题。
- 哪些事情蓝辉坚持做，哪些项目明确不做。

建议使用“车主痛点 → 蓝辉方法 → 可验证结果”结构，而不是品牌自我描述。

### 3. 把抽象理念变成可验证行为

当前三个理念卡“轻量升级 / 实用优先 / 审美表达”方向合理，但文案抽象。建议改成：

- 轻量升级：优先无损/可逆方案；需要改线或结构施工时提前说明。
- 实用优先：先确认车型、年款、场景与预算，再推荐项目。
- 审美表达：提供实车案例、材质样板和颜色对比，不只看效果图。

每张卡增加一个真实例子或施工标准链接。理念必须能对应到用户可观察的行为。

### 4. 新品牌不要反复强调“刚成立”

页面三次强调 2026 年成立，会持续提醒用户品牌很新，却没有同时提供团队经验、供应链、施工能力或门店证明。

建议：

- Hero 不再突出成立年份。
- 在品牌历程中保留一次成立时间即可。
- 如果团队、工厂、供应链拥有更早经验，可在有证据的前提下写“品牌成立于 2026，团队/供应链经验始于……”。
- 没有可验证历史时，重点表达当前能力和服务标准，而不是放大时间长度。

### 5. “发展起点”需要真实内容或合并

目前发展起点只有两张卡：2026 品牌成立、顺德大良店启航，信息与前文重复。建议二选一：

- 如果真实历程内容不足：把它合并为一条简洁的“从顺德大良出发”。
- 如果已有真实节点：展示 3–5 个完成状态的时间点，并链接完整品牌历程。

不要为了时间线形式填充计划或占位里程碑。

## P1：增加可信证据

### 推荐的证据模块

1. 顺德大良店实景：门头、接待区、施工工位、停车提示。
2. 施工流程：车型确认、方案确认、施工记录、交付验收。
3. 真实团队：技师照片、职责、可验证培训/资质。
4. 材料与供应链：只展示已确认的品牌、型号和授权关系。
5. 施工案例：车型、项目、施工时长、前后对比。
6. 服务承诺：质保范围、售后路径、明确不覆盖的情况。
7. 真实资质：审核通过后再展示。

证据不需要很多，但每项必须真实、清晰、可核验。

### 图片建议

当前品牌主体没有任何图片。建议至少准备：

- 1 张 Hero 车辆/施工图。
- 1 张门店外观。
- 2–3 张工位与施工细节。
- 2–3 个真实案例前后对比。
- 1 张团队合照或施工团队工作照。

图片统一 WebP/AVIF，声明尺寸和 `sizes`；人物与车牌需要授权和脱敏。

## P1：建立明确的转化出口

主内容区当前 0 链接、0 按钮，是一个完全的内容死胡同。

建议至少增加：

- Hero：获取车型方案 / 查看顺德大良店。
- 理念或流程区：查看施工流程。
- 真实证据区：查看案例。
- 品牌导航卡：品牌历程 / 真实资质（准备完成后）/ 品牌资讯。
- 页尾 CTA：微信咨询、电话、导航。

CTA 渠道必须和实际行为一致。当前“企业微信咨询”实际打开公众号二维码的问题应同步修复。

## P1：推荐页面结构

1. Hero：品牌主张 + 真实图片 + 双 CTA。
2. 为什么创立蓝辉：车主问题与品牌方法。
3. 三项品牌原则：原则 → 具体行为 → 真实例子。
4. 车型适配与施工标准。
5. 门店、团队和材料证据。
6. 真实案例。
7. 已验证资质与品牌历程入口。
8. 顺德大良店与最终咨询 CTA。
9. 精简 Footer。

## P2：语义、视觉与可访问性

### 标题层级

当前 `ABOUT LANHUI` 使用 H2，“关于蓝辉轻改”使用 H3。建议：

- `ABOUT LANHUI` 改为 `<p>`。
- “关于蓝辉轻改”使用 H2。
- 其他主要区块保持 H2，卡片标题使用 H3。

### 对比度

- 修复 axe 检出的 19 个严重级对比度节点。
- 重点处理 Footer 的 `text-zinc-500/600` 链接、描述和备案信息。
- 验收标准：axe WCAG 2 AA `color-contrast` 为 0。

### 触控目标

- 移动菜单当前 40×40px，应提升至至少 44×44px。
- Footer 文字链接增加行高和可点击区域。
- 新增 CTA 保持至少 44px 高和清晰 focus ring。

### 视觉层级

- 当前品牌页延续全站“黑底 + 渐变 + 图标卡”，但缺少独有品牌识别。
- 建议用真实摄影、Logo 留白规范、橙色主转化色和少量蓝色技术辅助色形成品牌系统。
- 减少大面积空黑区和纯装饰光斑，让图片和证据承担视觉重点。

### 动效

- 卡片 hover 和 Header 动效补充 `prefers-reduced-motion`。
- 品牌页不需要大量装饰动画；可使用轻微的图片揭示和时间线进度，但不能替代内容。

## 开发拆分

### Slice A：可信边界（0.5–1 天）

- 暂停公开占位资质。
- 校验品牌历史和完成状态。
- 隐藏 Footer 占位联系方式。
- 修正过宽承诺与 CTA 渠道文案。

### Slice B：品牌叙事和信息架构（1–2 天）

- 新 Hero 和品牌主张。
- 重写“为什么存在 / 我们如何做”。
- 理念改为具体行为。
- 合并重复的成立/起点内容。
- 加品牌子页和 CTA 导航。

### Slice C：真实证据和视觉（2–4 天，依赖素材）

- 门店、团队、施工、材料和案例图片。
- 施工标准与服务承诺。
- 已审核资质展示。
- 页面视觉系统统一。

### Slice D：质量收口（0.5–1 天）

- 标题语义、对比度、触控目标、focus、reduced motion。
- 390 / 768 / 1440 Playwright 与 axe 回归。

## 验收标准

- 主内容至少有一个明确主 CTA 和一个次 CTA。
- CTA 文案与实际微信/电话/导航行为一致。
- 页面至少包含门店、施工、团队或案例中的三类真实证据。
- 未验证证书、占位资质和计划里程碑不出现在公开页面或 sitemap。
- 品牌事实在首页、品牌页、历史页、Metadata 中一致。
- `ABOUT LANHUI` 不占用内容标题层级，H1/H2/H3 结构清晰。
- 生产页面不出现“待补充”“待确认”、示例邮箱或待备案文本。
- 移动端关键触控目标不小于 44×44px。
- axe WCAG 2 AA 无严重级违规。
- 390 / 768 / 1440 无横向滚动。

## 风险与依赖

- 品牌成立时间、门店开放时间、团队经验和供应链关系必须由业务方确认。
- 资质名称、颁发方和授权关系不能根据行业常识推断或编造。
- 门店、团队和车辆图片需要授权，车牌与客户信息需要脱敏。
- “无损安装”“不动原车结构”“规范施工”等表述必须限定项目和适用车型。
