# 首页 UI / UX 审计与可部署改进方案

审计日期：2026-07-11  
页面：`/`  
视口：390×844、768×1024、1440×1000  
方法：Playwright Chromium、生产构建交互复测、axe WCAG 2 A/AA/2.1 AA、代码结构核对

## 结论

首页技术底座稳定，但商业体验仍像“内容目录页”，不像“能建立信任并促成咨询的本地汽车服务首页”。最大问题不是美化细节，而是：首屏缺少真实视觉证据、服务与产品模块重复、核心咨询 CTA 的文案和实际行为不一致、占位联系方式削弱可信度。

建议先完成 P0 的转化与信任修复，再做视觉升级。只换颜色、圆角或动效不会解决当前的核心问题。

## 实测摘要

- 390px：页面高 7369px；产品入口标题位于 y=3316，约滚动 4 个首屏后才能看到。
- 768px：页面高 5376px。
- 1440px：页面高 4372px。
- 三个视口均无横向溢出；H1 唯一，标题顺序合理。
- 首页仅渲染 2 张内容图片，且两张都是同一品牌 Logo；没有汽车、施工、门店、案例或产品实拍。
- axe 检出 21 个 `color-contrast` 严重级节点，集中在 `text-zinc-500/600` 的说明、链接、Footer 和“即将上线”文本。
- 首页 47 个不重复内部路径全部返回正常，无 4xx/5xx。
- 生产模式下移动菜单可打开、锁定背景滚动、Escape 关闭并恢复焦点；咨询弹窗同样通过。
- `npm run build` 成功。

## P0：上线前优先修复

### 1. 咨询 CTA 语义与结果不一致

Hero 按钮写的是“企业微信咨询 / 添加企业微信咨询车型方案”，实际打开的是“关注蓝辉轻改公众号”二维码。用户期待一对一咨询，却被导向公众号关注，属于转化承诺错位。

立即可部署方案：

- 若现阶段只有公众号：按钮改为“扫码获取车型方案”，弹窗说明明确“关注公众号后回复车型”。
- 若业务目标是一对一获客：换成企业微信员工活码，按钮保持“微信咨询车型方案”，弹窗补充“添加后发送车型/年款/需求”。
- Header 的“联系我们”、Hero CTA、移动菜单 CTA 使用同一动作名称和同一渠道。
- 增加 `wechat_consult_open`、`wechat_qr_view`、`store_cta_click` 埋点，区分入口来源。

涉及文件：`src/components/WeChatConsultButton.tsx`、`src/components/shared/WeChatConsultModal.tsx`、`src/lib/contact-channels.ts`、`src/components/Header.tsx`。

### 2. 不要在公开首页展示占位联系方式

当前 Footer 会展示“联系方式待补充”“详细地址待补充”“营业时间待确认”“lanhui@example.com”“备案号待备案”。这会直接伤害本地服务品牌的可信度，也让用户无法完成到店或电话咨询。

立即可部署方案：

- 真实数据未确认前，Footer 只显示已确认的“广东佛山·顺德大良”和微信入口；不要渲染假邮箱或“待补充”字段。
- 数据确认后，将地址链接到地图、电话使用 `tel:`、营业时间写清工作日/节假日规则。
- 对字段增加 `isPublic` 或数据有效性判断，避免占位符再次进入生产环境。

涉及文件：`src/lib/brand.ts`、`src/components/Footer.tsx`、`src/components/cta/PhoneCta.tsx`。

### 3. 用真实证据替代纯图标陈述

汽车改装是高视觉、高信任决策。当前首页只有 Logo 图片，其余全是渐变、线框图标和文字；“800 亩制造厂区”“持证技师”“标准施工”“品牌质保”都没有证据承接。

立即可部署方案：

- Hero 右侧增加一张高质量门店施工或完成车辆实拍，移动端放在价值主张之后、CTA 之前或使用低干扰背景图。
- 新增 3 个真实案例：车型 + 项目 + 施工时长 + 前后对比 + 到店 CTA。
- 新增“顺德大良店”实体卡：门头/工位、地址、营业时间、导航与微信。
- 所有制造、资质、质保数字只使用可核验素材；不能提供证据的表述降级为中性描述。

## P1：重构信息架构与视觉层级

### 推荐首页顺序

1. Header：品牌、产品、车型、案例、门店；保留一个主 CTA。
2. Hero：一句结果导向标题 + 一句适用人群 + 真实车辆/施工图 + 主 CTA“获取车型方案” + 次 CTA“查看适配车型”。
3. 车型快捷查找：先选品牌，再进车型专题；这是用户最自然的入口。
4. 热门升级方案：新车保护、外观焕新、上下车便利、座舱舒适，以场景而非内部产品分类组织。
5. 真实案例 / 前后对比：承担审美与信任证明。
6. 施工流程与保障：到店评估 → 方案确认 → 标准施工 → 验收售后。
7. 顺德大良门店与最终 CTA。
8. 精简 Footer。

### 合并重复模块

“核心服务”4 张卡和“产品快速入口”6 张卡都在解释能做什么，且都使用相似图标卡，用户感知重复。建议：

- 删除独立的“核心服务”卡片墙。
- 保留 6 个产品入口，但换成真实产品/车辆图，并增加“适合谁 / 解决什么问题”。
- 将“品质与质保”移入独立的保障条；将“轻改方案库”改成车型查找入口。
- 产品卡顶部与卡内目前重复显示同一图标，合并为一个视觉焦点，减少约 48–64px 卡片高度。

涉及文件：`src/app/page.tsx`、`src/components/CoreServices.tsx`、`src/components/ProductsQuickEntry.tsx`。

### 统一品牌主色和 CTA 层级

Header 主 CTA 是橙色，Hero 主 CTA 是高饱和蓝色，产品模块又蓝橙并用；这让主操作识别不稳定。建议橙色作为全站转化色，蓝色作为“轻改装备”分类色。每个区块只保留一个主动作，次动作使用描边或文字链接。

### 优化 Hero 文案

当前标题只写品牌名，副标题和正文偏企业自述。建议改为结果导向：

- H1：`新能源车型轻改与车身膜，一站式适配施工`
- 支撑句：`顺德大良到店评估，覆盖问界、小米、极氪、理想等热门车型。`
- 证明条：`源头供应链`、`标准施工流程`、`车型专属方案`
- 中文文案统一使用全角标点，修复现有英文逗号。

涉及文件：`src/components/Hero.tsx`。

### 移动端增加持续可达的转化入口

390px 页面超过 7 屏，Hero 离开后咨询入口消失。建议增加底部安全区 CTA 条，仅在移动端显示：左侧“微信咨询”，右侧“到店导航”；滚动进入 Footer 时隐藏，避免重复。目标高度 56–64px，适配 `env(safe-area-inset-bottom)`。

## P2：可访问性与交互质量

### 对比度

- 将主要说明与 Footer 链接从 `text-zinc-500/600` 提升到至少 `text-zinc-400`，再用 axe 复验。
- “即将上线”、版权、备案信息不能用过暗灰色表达；弱化可以靠字号和层级，不只靠降低对比度。
- 验收标准：axe WCAG 2 AA `color-contrast` 为 0。

### 触控目标

- 移动菜单与关闭按钮当前为 40×40px；提升至至少 44×44px。
- 桌面下拉箭头按钮约 26×26px；扩大可点击区域，或让整项同时控制展开。
- 车型 chip 约 20–22px 高；移动端至少提供 44px 的行高/命中区域，视觉 chip 可以小，但点击热区要大。

### 键盘与下拉导航

顶部一级下拉可由按钮打开，但品牌下的车型 flyout 主要依赖 hover。增加 `focus-within` 展开逻辑，或改成可点击的二级 disclosure。若继续使用 `aria-haspopup="menu"`，需要补齐菜单语义与键盘行为；更简单的方式是把它作为普通导航 disclosure，不冒充应用菜单。

### 动效

为 Header 高度变化、卡片位移、箭头动画和移动抽屉补充 `prefers-reduced-motion` 降级；交互反馈保持 150–300ms。

## 可直接执行的开发拆分

### Slice A：转化真实性（0.5–1 天）

- 修正微信 CTA 与二维码渠道语义。
- 隐藏无效联系方式，补数据有效性判断。
- 加 CTA 埋点。
- 增加对应组件测试与 Playwright 交互测试。

### Slice B：首页结构与真实内容（2–4 天，取决于素材）

- 新 Hero（真实图 + 新文案 + 证明条）。
- 车型查找前移。
- 合并服务/产品重复卡片。
- 新增 3 个案例和门店实体卡。
- 移动底部 CTA。

### Slice C：无障碍与精修（1 天）

- 修复 21 个对比度节点。
- 统一触控目标。
- 修复 flyout 键盘路径与 reduced motion。
- 390 / 768 / 1440 回归与 axe 复验。

## 验收标准

- Hero 主 CTA 的文案、弹窗标题、二维码渠道完全一致。
- 生产页面不出现“待补充”“待确认”、示例邮箱或待备案文本。
- 首屏至少出现一张真实业务图片，首页至少有 3 个带车型和项目名称的真实案例。
- 390px 下，车型或热门方案入口在第 2 屏内出现；页面无横向滚动。
- 移动端关键按钮命中区域不小于 44×44px。
- axe WCAG 2 AA 无严重级违规。
- 移动菜单和咨询弹窗支持 Escape、背景滚动锁定、关闭后焦点恢复。
- 首页内部链接无 4xx/5xx。
- `npm run lint`、`npm run build`、首页 Playwright 测试通过。

## 风险与依赖

- 真实门店地址、电话、营业时间、企业微信活码必须由业务方提供；未确认前应隐藏而不是编造。
- 真实案例需要车主授权和车牌脱敏。
- “800 亩”“持证技师”“进口基材”“质保”属于高信任声明，发布前需准备可核验材料与适用范围。
- 首页视觉升级的质量上限主要受真实素材影响；如果没有实拍，优先安排门店、工位、车辆和施工细节拍摄。
